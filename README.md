# Plataforma de Gestión Gastronómica

Producto SaaS multi-tenant para restaurantes: menú digital, pedidos, comandas, reservas, promociones y herramientas de gestión.

## Punto de partida

El desarrollo comienza con una demo interna para la agencia, utilizando datos semilla basados en el menú de MUUD. MUUD será posteriormente el primer restaurante piloto para validar el producto en condiciones reales.
